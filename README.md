Laundry Services Web Application

About

This is a simple Laundry Services Web Application. I made this project to practice working with HTML, CSS, and JavaScript.

The application allows users to browse laundry services, add services to their cart, view the total amount, and book laundry services using a booking form.

Features

Displays different laundry services with images and prices

Allows users to add services to the cart

Allows users to remove services from the cart

Provides a booking form with name, email, and phone number

Sends booking details using EmailJS

Displays a booking confirmation message

Provides a newsletter subscription section

Operations Performed

1 Browse Services

Displays different laundry services with their images and prices.

2 Add Items

Allows users to select laundry services and add them to the cart.

3 Remove Items

Removes a service from the cart and updates the total amount.

4 Calculate Total

Calculates and displays the total amount of all services in the cart.

5 Book Now

Allows users to enter their full name, email address, and phone number in the booking form.

6 Email Confirmation

Sends the booking details to the configured email address using EmailJS.

7 Booking Message

Displays a confirmation message after the booking email is sent successfully.

8 Newsletter Subscription

Allows users to enter their name and email address to subscribe to the newsletter.

How to Run

Create three files named index.html, style.css, and script.js.

Add the respective code to each file.

Configure EmailJS with your Public Key, Service ID, and Template ID.

Open the index.html file in a browser.

Browse the available laundry services.

Click Add Items to add services to the cart.

Remove services when required.

Check the total amount.

Fill in the booking form and click Book Now.

Check the configured email address for booking details.
